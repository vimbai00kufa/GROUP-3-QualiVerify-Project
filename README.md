# GROUP-3-QualiVerify-Project
Software Engineering Practical Based Assignment
## Project Overview

This repository contains the implementation of the MIM736 Practical
Assignment for the Master of Commerce in Information Systems Management.

The project will be developed collaboratively using Python and Django,
following a structured Git and GitHub workflow.

## Technology Stack

- Python
- Django
- PostgreSQL
- pytest
- pytest-django
- Ruff
- GitHub Actions
- Git/GitHub

## Development Workflow

The project uses the following branch structure:

main
↓
develop
↓
feature branches

### Branch Rules

- `main` contains stable code.
- `develop` is the integration branch.
- New functionality must be developed on feature branches.
- Changes must be submitted through Pull Requests.
- Direct pushes to `main` are prohibited.
- Pull Requests require review before merging.
