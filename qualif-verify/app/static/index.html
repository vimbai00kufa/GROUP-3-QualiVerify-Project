Verify a qualification

Public endpoint — anyone can check whether a certificate is real. No login needed.

Search records

Requires the verifier or admin role. Matches holder name or certificate number.

Register a qualification

Requires the admin role. The record is signed (HMAC-SHA256) and an audit entry is written.

Audit log

Append-only history of every registration, search, verification and revocation. Admin only.
